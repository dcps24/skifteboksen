# 📦 Skifteboksen

**Skifteboksen** er en sesongskiftehjelp for norske foreldre med barn i barnehage, SFO og barneskole.

## Hva gjør appen?

Gir deg en sjekkliste for hva barn skal ha på seg, basert på sesong, setting og alder.

## Funksjoner

- 4 sesonger × 3 settinger × 4 aldersgrupper
- Norsk (bokmål)
- Offline-først via localStorage
- Tilpassbar: legg til egne plagg
- Mobil-først, WCAG 2.1 AA
